# CORE: Compliance Oversight & Regulatory Enforcement

A proposal to the **NITDA Innovation Challenge 2.0** (Idea2Impact Programme, 2026).

CORE tracks NDPA, GAID and CAR compliance for every organisation NITDA regulates. It flags missed deadlines automatically and gives enforcement officers a risk-ranked queue of who to act on first.

## What's in this repo

| Path | What it is |
|---|---|
| `index.html` | Landing page |
| `prototype/index.html` | Working dashboard prototype: overview, entity registry, enforcement queue, audit trail |

Both are single static HTML files with no build step. All entities and figures in the prototype are fictional examples. Actions logged in the prototype are saved in the visitor's own browser only.

## Publish with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`, and the prototype at `.../prototype/`.
